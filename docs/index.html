PostalVision

End-to-End Deep Neural Network OCR & Address Extraction System

Automatically reads postal envelopes, transcribes handwritten addresses using a custom CRNN + BiGRU + CTC architecture designed from first principles, and extracts structured postal fields.

Capabilities

Intelligent Postal Processing

From raw envelope photographs to structured digital postal records in milliseconds.

👁

Layout Analysis

CLAHE contrast enhancement, bilateral filtering, morphological dilation, and connected component line bounding.

🧠

Custom CRNN

Asymmetric pooling CNN + 2-layer BiGRU + CTC head. Height 32 to 1 while preserving W/4 sequence length.

✍️

Real Handwriting

1.9M+ real human handwritten glyphs from all 6 EMNIST splits. Letters A-Z AND digits 0-9.

📍

Address Parsing

Regex and heuristic extractor for Name, Premise, Street, City, State, and 6-digit PIN with geocoding.

📷

Live Camera

Real-time webcam scanner with virtual envelope simulator, viewfinder reticle, and one-click capture.

📊

Export & Analytics

CSV manifest export, batch processing, editable fields with live JSON sync, and speech synthesis.

Neural Architecture

ScratchPostalCRNN

Every layer designed from first principles. Zero pretrained dependencies.

1

Stem Conv

5x5, 32ch + BN + LeakyReLU + MaxPool(2x2)

2

Detail Block

3x3, 64ch + BN + LeakyReLU + MaxPool(2x2)

3

Glyph Block

2x 3x3, 128ch + Asymmetric MaxPool(2x1)

4

Morphology

2x 3x3, 256ch + Asymmetric MaxPool(2x1)

5

Collapse

2x1 Conv, 256ch. H=1

6

Map-to-Seq

Linear 256->192 + LayerNorm

7

BiGRU

2-Layer Bidirectional GRU, h=128

8

CTC Head

Linear -> 76 classes + CTC decoding

Getting Started

Quick Start

1

Clone & Install

git clone https://github.com/azij2023/PostVision.git cd PostVision && pip install -r requirements.txt
2

Generate Samples

python main.py generate --num 5
3

Train Model

python main.py train --dataset emnist --epochs 10
4

Launch Web UI

python webapp/app.py
